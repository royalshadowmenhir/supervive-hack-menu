## 🧩 About

**SUPERVIVE Hack Menu** is a curated list of SUPERVIVE open-source tools:

- **Overlays** — on-screen helpers, layout notes, radar viewer, minimap enhancer
- **Quality-of-Life Helpers** — loot tracker, config manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Radar Overlay — view nearby entities for practice
- Show Loot — highlight item drops and loot spots
- Replay Notes — record and review match runs
- Playback Speed — adjust replay playback for study (0.1x to 5x)

### Wallhack
- Skin Catalog — browse skins, colors, trails, effects
- Custom Skin Notes — organize character cosmetics
- Solid HUD — improved HUD visibility and layout

### Aimbot
- Practice Mode Notes — segment study on any map
- Gravity Control — manually adjust gravity for practice
- Jump Buffer Notes — chain complex maneuvers in the editor
